# EduInSight — Screen Plan

## 1. Shared Screens

### 1.1 Login Page

- EduInSight logo and purpose
- University email
- Password
- Remember me
- Forgot password
- Sign-in button
- Student registration link

The user will not select a role. EduInSight will identify the role after login.

### 1.2 Forgot Password Page

- University email
- Reset-password request
- Confirmation message

### 1.3 Unauthorised Access Page

Shown when a user attempts to access a page outside their role.

## 2. Student Screens

### 2.1 Student Dashboard

- Welcome message
- Submit New Feedback button
- Submitted feedback count
- Received feedback count
- Feedback under review
- Actions taken
- Recent feedback
- University updates

### 2.2 Submit Feedback Page

- Department
- Course or university service
- Section
- Topic or feedback area
- Multilingual feedback box
- Anonymous or identified option
- Privacy information
- Submit button

Supported input:

- English
- Urdu
- Roman Urdu
- Mixed Urdu–English

### 2.3 Feedback Confirmation Page

- Submission confirmation
- Feedback reference
- Selected course or service
- Initial status
- View Status button

### 2.4 My Feedback Page

- Previous submissions
- Submission dates
- Categories
- Current statuses
- Published responses

### 2.5 Feedback Details Page

- Original feedback
- Submitted date
- Current status
- Status timeline
- Published action update

### 2.6 University Updates Page

- Academic updates
- Facilities updates
- Service updates
- Action-completion announcements

## 3. Teacher Screens

### 3.1 Teacher Dashboard

- Assigned course and section
- Total feedback
- Learning concerns
- High-priority issues
- Resolved issues
- Top learning bottlenecks
- Feedback trend
- AI insight
- Action progress

### 3.2 Learning Insights Page

- Learning-problem clusters
- Related feedback count
- Percentage
- Trend
- Priority
- Course, section and topic filters

### 3.3 Learning Problem Details Page

- Exact reported problem
- Course, section and topic
- Supporting anonymised feedback
- Priority explanation
- AI-generated interpretation
- Suggested teaching response
- Human-review warning

### 3.4 Teacher Actions Page

- Acknowledge issue
- Create teaching action
- Add deadline
- Update action status
- Publish student-facing response
- Forward issue to coordinator

## 4. Administrator Screens

### 4.1 Administrator Dashboard

- Total university feedback
- High-priority issues
- Actions in progress
- Overdue actions
- Resolved issues
- Feedback by area
- Priority issues
- Institutional trend
- Action accountability

### 4.2 Institutional Issues Page

- Academic issues
- IT issues
- Facilities issues
- Library issues
- Student-service issues
- Department, category and date filters

### 4.3 Institutional Issue Details Page

- Problem summary
- Affected area
- Related feedback
- Supporting evidence
- Priority explanation
- Suggested responsible department
- Current action status

### 4.4 Action Management Page

- Assign responsible department
- Assign action owner
- Add deadline
- Update progress
- Identify overdue actions
- Close resolved issues
- Publish approved response

### 4.5 User Management Page

- View users
- Approve teacher accounts
- Assign teachers to courses
- Manage user roles
- Deactivate accounts
